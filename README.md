# Little Fern free frog page

This public static site contains the free Pond Patrol colouring page (A4 and US Letter), its preview, and links to the paid Pond Patrol and Christmas Woodland Hunt Etsy packs. It contains no Warehouse code, credentials, customer information, or paid pack PDFs. The root-level public files include `index.html`, `frog-preview.jpg`, `christmas-woodland-hunt.jpg`, the two free frog PDFs, and `.nojekyll`.
